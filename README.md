# open-energy-data

A curated catalog of energy datasets, network models, and data portals.

Resources are grouped by their main content and listed once. Access requirements are shown per entry; some sources require registration or a subscription.

Descriptions identify the data form, variables, and temporal resolution and coverage where documented. Publication update frequency is separate from the sampling interval.
